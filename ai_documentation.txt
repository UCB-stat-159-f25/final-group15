## What AI did
AI was used to:
- Explain error messages and propose fixes
- Provide shell command sequences to build the MyST site and deploy it to the gh pages branch using git worktree
- Provide templates for repository documentation, including README sections and DOI badge formatting
- Provide guidance on what components should be included for reproducibility, such as environment.yml, Makefile targets, and notebook execution expectations

## What humans did
Team members:
- Chose the dataset and defined the research questions
- Wrote the analysis code, functions, and tests in the repository
- Interpreted results, created figures, and wrote the narrative in main.ipynb
- Reviewed and edited all text for correctness and clarity
- Ran builds, executed notebooks, and verified outputs
- Performed final deployment, release, and Zenodo archival steps

## Verification
We reviewed AI suggested commands before running them and adjusted paths and filenames to match our repository structure. We also manually checked that:
- All notebooks run successfully

- PDF builds exist in pdf_builds
- The GitHub Pages site renders correctly
